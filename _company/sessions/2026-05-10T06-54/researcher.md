### **Phase 1: 타겟 기관 및 과제 식별 (Discovery & Targeting)**

**🎯 목표:** 연구 주제와 가장 관련성이 높은 잠재적 정부/공공기관 및 등록된 연구과제 목록 확보.

**🔎 데이터 수집 경로 현실성 검토:**
1.  **기관 리스트 확보 (최우선 타겟):**
    *   **검토 내용:** Phase 1의 성공을 위해 '최우선 타겟 기관(Phase 1 리스트)'의 정의가 명확해야 합니다. 현재 단계에서는 **'AI/첨단기술 분야 정부 부처 및 핵심 공공 연구기관 리스트'**를 확보하는 것이 최우선입니다.
    *   **현실성:** 단순 검색으로는 불충분하며, 관련 법규/정책 문서(예: R&D 지원 사업 공고)를 역추적하여 기관별 지원 분야를 매핑하는 구조가 필요합니다.
    *   **권장 경로:** 정부 부처별(예: 과기정통부, 산업부 등) R&D 지원 사업 공고 시스템 API 또는 정기 발행되는 공식 리스트 문서 모니터링.
2.  **연구과제 데이터베이스 매핑:**
    *   **검토 내용:** 기관별로 등록된 연구과제 DB가 단일화되어 있지 않을 가능성이 높으므로, 기관별로 상이한 데이터 포맷(JSON, XML, HTML 등)을 처리할 수 있는 **다중 포맷 파싱 모듈** 설계가 필요합니다.
    *   **기술적 요구사항:** 기관별로 상이한 검색 필터(키워드, 주제 태그)를 유연하게 처리할 수 있는 **메타데이터 추출 프레임워크**가 필요합니다.

**⚙️ 구체적인 데이터 요구사항:**
*   기관별 등록 공고/DB 접근 URL 목록.
*   각 기관에서 사용하는 **메타데이터 스키마(필수 컬럼 정의)**. (예: 과제명, 지원 분야 태그, 담당 부서 ID, 공고 마감일, 예산 규모 등)
*   초기 필터링을 위한 **키워드/태그 매핑 테이블** (검색어 $\rightarrow$ 기관별 필터 값).

### **Phase 2: 데이터 수집 및 정제 (Data Acquisition & Refinement)**

**🎯 목표:** 식별된 과제에 대한 상세 정보(평가 기준, 요구사항)를 수집하고 데이터의 신뢰도를 확보.

**🔎 데이터 수집 경로 현실성 검토:**
1.  **상세 정보 추출 경로:**
    *   **검토 내용:** Phase 1에서 확보한 기관별 접근 경로(API 또는 크롤링 대상 URL)를 기반으로, **'상세 정보 추출 시나리오(Step-by-Step)'**가 필요합니다.
    *   **현실성:** 대부분의 공공기관 웹사이트는 정보 접근 시 동적 로딩(JavaScript)을 사용하거나, 로그인 인증 절차를 요구합니다. 따라서 단순 HTTP 요청으로는 정보 획득이 불가능하며, **인증/세션 관리 로직**을 포함한 복잡한 크롤링 모듈이 필수적입니다.
    *   **권장 경로:** Phase 1에서 정의된 URL에 대한 **동적 콘텐츠 추출을 위한 Headless Browser 기반 크롤링 시나리오** 및 API 호출 성공/실패 로직 정의.
2.  **데이터 정형화:**
    *   **검토 내용:** 수집된 비정형 데이터를 ALTIT KOREA의 내부 DB 스키마에 맞추어 정제하는 과정이 필요합니다.
    *   **기술적 요구사항:** 데이터 클렌징(Cleaning), 표준화(Normalization)를 위한 **ETL(Extract, Transform, Load) 파이프라인** 설계. (특히, 기관별로 상이한 용어를 통일하는 매핑 로직 구현 필요).

**⚙️ 구체적인 데이터 요구사항:**
*   **Phase 2 전용 API/크롤링 엔드포인트 명세서 초안:** (Developer 에이전트와 협업 필요) 각 단계별로 필요한 **API 호출 파라미터, 예상 응답 구조(Schema), 에러 핸들링 코드** 명세.
*   데이터 정제 로직에 필요한 **규칙 기반(Rule-based) 변환 함수 목록**.

### **Phase 3: 제안서 연계 및 최종 검토 (Proposal Alignment & Final Review)**

**🎯 목표:** 수집된 데이터를 바탕으로 ALTIT KOREA의 강점과 연결하여 제안서에 최적화하고 최종 검토.

**🔎 데이터 수집 경로 현실성 검토:**
1.  **Relevance 점수 모델링 기반 데이터 준비:**
    *   **검토 내용:** Business 측면에서 정의된 'Relevance 점수 모델링 기준'을 실제로 적용하기 위해서는, **'ALTIT KOREA의 강점(기술/데이터)'에 대한 정량적 데이터**가 필요합니다.
    *   **현실성:** 현재는 'ALTIT KOREA의 강점'에 대한 데이터 자체가 부족하므로, Phase 1/2에서 수집된 과제 정보와 **ALTIT KOREA의 기술 스택(현재 보유 역량)**을 매핑하는 기준 데이터셋 구축이 필요합니다.
    *   **권장 경로:** **기술 역량(Skill Matrix)** 데이터셋 구축 및 Phase 2에서 수집된 과제 요구사항과의 **매칭 알고리즘** 개발.
2.  **최종 리소스 투입 우선순위 데이터:**
    *   **검토 내용:** Low/Mid/High Risk 시나리오별 비용 예측을 위해, 각 과제 단계(Phase 1, 2, 3)에 필요한 **리소스 투입 예측치**를 산출할 수 있는 데이터 구조가 필요합니다.
    *   **기술적 요구사항:** Phase 2에서 정의한 복잡도(Complexity Score)와 Phase 3의 목표 요구사항을 결합하여, **리소스 수요 예측 모델(Demand Forecasting Model)**에 투입될 입력 데이터 정의.

**⚙️ 구체적인 데이터 요구사항:**
*   **Relevance 점수 모델링을 위한 매핑 기준 테이블:** (과제 요구사항 $\rightarrow$ ALTIT KOREA 역량 점수)
*   **리소스 예측 모델 입력 변수 정의서:** (Phase별 난이도 점수, 예상 소요 인력/시간 등)
