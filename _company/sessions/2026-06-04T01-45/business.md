# SOP 초안: 연구과제 데이터 추출 프로세스 (수집-정제-매핑 3단계)

## 1. 개요
본 문서는 정부 및 공공기관의 연구과제 정보를 수집, 정제, 그리고 내부 DB 스키마 V1에 매핑하는 전체 데이터 추출 프로세스의 상세 단계별 작업 분배 계획 및 각 단계의 성공/실패 기준(KPI 초안)을 정의한다.

## 2. 전체 워크플로우 개요
전체 프로세스는 다음 세 단계로 구성되며, 각 단계는 이전 단계의 산출물을 입력으로 사용한다.

**[단계 1: 데이터 수집 (Acquisition)]** $\rightarrow$ **[단계 2: 데이터 정제 (Refinement)]** $\rightarrow$ **[단계 3: 데이터 매핑 (Mapping)]**

## 3. 단계별 상세 작업 분배 및 기준

### 단계 1: 데이터 수집 (Acquisition)
**목표:** 정의된 타겟 기관별/분야별 가이드라인에 따라 **잠재적 원천 데이터의 포괄적인 수집** 및 초기 추출.
**성공 기준 (KPI 초안):**
*   **Coverage Rate:** 목표 타겟 기관/분야별 데이터 소스 목록 중 **최소 80% 이상**의 관련 원천 데이터를 성공적으로 식별 및 추출 완료.
*   **Completeness Score:** 수집된 데이터 항목 수 대비, 필수 메타데이터(제목, 출처, 등록번호 등) 누락률 **5% 미만** 유지.
*   **Source Integrity:** 수집된 데이터의 원천 출처(URL/문서명) 명확성 점수 **4.5/5점 이상** (데이터 추적 가능성).

### 단계 2: 데이터 정제 (Refinement)
**목표:** 수집된 원천 데이터를 내부 시스템(DB 스키마 V1)에 적합하도록 **표준화, 오류 검증, 형식 보정**을 통해 데이터 품질을 확보한다.
**성공 기준 (KPI 초안):**
*   **Data Validity Rate:** 정제 과정에서 발견된 오류(예: 필수 필드 누락, 형식 불일치) 중 **자동 복구/수정 성공률 95% 이상** 달성. (수동 개입 필요 오류는 5% 미만으로 제한)
*   **Standardization Compliance:** 정제된 데이터의 필수 필드(예: 연구 주제 분류 코드, 기간 형식)가 **DB 스키마 V1 정의된 표준 형식(Enum/Format)을 100% 준수**해야 함.
*   **Data Consistency Score:** 정제된 데이터 간의 내부 논리적 일관성 검증 통과율 **98% 이상**. (예: 연구 기간의 시작일/종료일 논리적 순서 검증).

### 단계 3: 데이터 매핑 (Mapping)
**목표:** 정제된 데이터를 PostgreSQL DB 스키마 V1의 구조와 비즈니스 규칙에 맞게 **최종적으로 매핑**하고 데이터 무결성을 최종 확인한다.
**성공 기준 (KPI 초안):**
*   **Mapping Accuracy:** 정제된 데이터가 DB 컬럼에 매핑되는 과정에서 발생하는 **데이터 손실(Loss) 또는 오매핑(Mismapping) 건수 0건** 달성.
*   **Schema Integrity Check:** 매핑 완료된 데이터셋에 대해 DB 스키마 V1의 모든 제약 조건(NOT NULL, UNIQUE 등)이 **자동 테스트를 통해 100% 통과**해야 함.
*   **Latency Check:** 데이터 수집부터 최종 DB 삽입까지의 **평균 처리 시간(Latency)이 목표치(예: 5분 이내)를 초과하지 않아야 함.**

## 4. 다음 단계 (역할 분배)
*   **Researcher:** 위 KPI 초안을 검토하고, 각 지표에 대한 **측정 도구(Metric Definition)**를 구체화할 것.
*   **Developer:** 단계 2의 'Standardization Compliance' 항목을 기반으로, **데이터 정제 모듈 내에서 적용할 구체적인 변환/검증 로직(Test Case)**을 설계할 것.
*   **Business:** 단계 1과 2의 KPI 초안을 검토하고, **'Data Validity Rate'와 'Standardization Compliance'의 비즈니스 영향도**를 평가하여 최종 목표 수치를 확정할 것.
