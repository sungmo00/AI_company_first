### 1. MVP 데이터 수집 플로우 (Flow Diagram 상세 정의)

이 단계는 가설 검증의 각 마일스톤을 명확히 구분하고, 데이터 수집이 어떻게 비즈니스 목표와 연결되는지 보여줍니다.

| 단계 | 목표 (Goal) | 주요 활동 (Key Activities) | 입력 데이터 (Input Data) | 출력물 (Output Dataset/Artifact) | 책임 에이전트 | 검증 기준 (Validation Metric) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1. 정의 (Define)** | 가설 검증을 위한 핵심 변수 및 측정 기준 확정 | 최종 제안서 요구사항(RFP) 분석, 핵심 성공 요인(CSF) 매핑, 타겟 기관별 요구사항 상세화 | 연구과제 목록, 잠재적 파트너 기관의 RFP/가이드라인 | **핵심 변수 정의서 (Feature Set Definition)**: 수집해야 할 최소/필수 데이터 컬럼 및 정의 | Researcher / 현빈 | 변수 정의의 포괄성 (Coverage) |
| **2. 설계 (Design)** | 데이터 수집의 구조 및 가중치 모델 정의 | 독립 변수(X)와 종속 변수(Y) 매핑, **Relevance Score Model ($W_1, W_2, W_3$) 구체화**, DB Schema 초안 검토 | 핵심 변수 정의서, 기존 데이터 구조 (DB Schema 참조) | **MVP 데이터 수집 플로우/로직 설계서**: 데이터 흐름도 및 가중치 할당 로직 명세 | 코다리 / Researcher | 모델의 논리적 일관성 (Consistency) |
| **3. 수집 (Collect)** | 정의된 플로우에 따라 실제 데이터 확보 | 타겟 기관별/연구 분야별 데이터 요청 및 수집 전략(API, Crawl) 실행 | 설계된 플로우, 접근 권한/API Key | **정제되지 않은 원시 데이터셋 (Raw Data)**: 수집된 모든 원본 데이터 | Researcher / Instagram | 데이터 수집 완료율 (Completion Rate) |
| **4. 검증 (Validate)** | 데이터의 유효성 및 가설 적합성 평가 | 데이터 정제(Cleaning), 이상치 탐지, **가중치 기반 스코어링 적용**, 최종 데이터셋 확정 | 원시 데이터셋, 정제 로직, 가중치 모델 | **검증된 MVP 데이터셋 (Validated Dataset)**: 분석 및 학습에 즉시 사용 가능한 최종 데이터 | 코다리 / Developer | 데이터 품질 지표 (Data Quality Index) |

### 2. 핵심 가중치 모델 설계서 (Relevance Score Model) 상세

장기 목표인 '수익화 모델 검증'을 위해, 단순히 데이터 수집이 아닌 **'가설의 성공 가능성'**에 초점을 맞춘 가중치 로직을 설계합니다.

$$\text{Relevance Score} = W_1(\text{Strategic Fit}) \times W_2(\text{Policy Alignment}) \times W_3(\text{ALTIT Advantage})$$

| 가중치 요소 | 약어 | 설명 (측정 기준) | 가중치 ($W_n$) 산정 근거 (CEO 지시 반영) | 측정 지표 (Metric) 예시 |
| :--- | :--- | :--- | :--- | :--- |
| **전략적 적합성** | $W_1$ (Strategic Fit) | 수집하려는 연구과제가 ALTIT KOREA의 장기 비즈니스 목표(수익화 모델)와 얼마나 직접적으로 연결되는가? | **0.5 (최우선)**: 장기 투자 방향을 우선시하여, 비즈니스 성과에 가장 큰 영향을 미치는 요소로 설정. | 연구 주제의 시장 성장성 예측치, 타겟 산업과의 직접적 연관성 점수. |
| **정책 연관성** | $W_2$ (Policy Alignment) | 해당 연구과제가 정부 및 공공기관의 현재 정책 방향(R&D 우선순위)과 얼마나 부합하는가? | **0.35**: 공공기관 연구과제 채택이라는 회사 핵심 목표 달성을 위한 필수 조건. | 정부 부처의 R&D 투자 비중, 최근 3년간 관련 정책 기조 변화 빈도. |
| **ALTIT 우위성** | $W_3$ (ALTIT Advantage) | 해당 연구과제를 수행할 때, 경쟁사 대비 ALTIT KOREA가 제공할 수 있는 차별화된 기술/자원 우위성은 어느 정도인가? | **0.15**: 실행 가능성을 높이기 위한 차별화 요소로, 초기 데이터 수집 단계에서는 보조적 역할. | 기술 난이도 대비 확보 가능한 내부 전문성 점수, 데이터 수집의 희소성. |

**가중치 적용 지침:**
*   $W_1$의 점수가 낮더라도, $W_2$와 $W_3$가 매우 높다면 (예: 정책적으로 매우 유망한 과제), 전체 점수는 **'높음'**으로 평가될 수 있습니다.
*   개발팀은 이 가중치 모델을 통해 **데이터 수집 우선순위**를 결정해야 합니다.

### 3. 공유용 요약 문서 (Executive Summary Draft)

**문서 제목:** MVP 데이터 수집 및 가설 검증을 위한 데이터 플로우 설계 (P1-2)

**대상:** 비즈니스 팀, 개발팀

**목표:** '수익화 모델 검증' 가설을 입증하기 위한 최소한의 핵심 데이터를 효율적으로 수집하고, 이 데이터에 가중치를 부여하여 분석 준비를 완료한다.

**주요 내용:**
1.  **데이터 수집 4단계 로드맵:** (위의 표 참조) 데이터가 '정의'에서 시작하여 최종적으로 '검증된 데이터셋'으로 완성되는 과정을 이해한다.
2.  **핵심 가중치 모델 (Relevance Score):** 데이터의 중요도를 결정하는 3가지 핵심 축($W_1$: 전략적 적합성, $W_2$: 정책 연관성, $W_3$: ALTIT 우위성)을 명확히 정의한다.
3.  **실행 지침:** 데이터 수집 단계(Step 3)에서는 이 가중치 모델을 기반으로 **'어떤 데이터를 우선적으로 수집할지'**에 대한 의사결정 기준을 제공한다.
