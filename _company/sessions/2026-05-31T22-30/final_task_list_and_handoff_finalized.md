# 최종 Task List 인계 확정본 (Developer & Researcher 병렬 작업 지시)

## 🎯 분배 목표
PostgreSQL DB 스키마 설계 착수와 데이터 추출 프로세스(SOP) 구체화 및 타겟 기관 접근 경로 확보를 병렬적으로 진행하여, 데이터 파이프라인의 핵심 기반을 즉시 구축합니다.

## 🧑‍💻 Developer (PostgreSQL DB 스키마 설계 담당)
*   **주요 임무:** Researcher가 정의한 최종 데이터 항목 정의서(컬럼 정의서)를 기반으로 PostgreSQL DB 스키마 설계 착수를 즉시 시작합니다.
*   **인계 지시사항:** 데이터 항목 정의서(컬럼 정의서)를 기준으로 **최소 3단계 이상의 정규화된 DB 스키마 초안**을 설계하고, 데이터 타입 및 관계 설계를 완료하십시오.
*   **마감:** [D-Day + 3일]까지 초기 스키마 초안을 완료하여 Developer에게 인계하십시오.

## 🧑‍🔬 Researcher (SOP 구체화 및 접근 경로 확보 담당)
*   **주요 임무:** 데이터 추출 프로세스(SOP)의 세부 워크플로우 구체화와 최우선 타겟 기관별 접근 경로 및 인증 정보 확보를 동시에 진행합니다.
*   **인계 지시사항 1 (SOP):** 데이터 수집, 정제, 매핑을 포함하는 **데이터 추출 프로세스 정의서(SOP)**의 상세 단계별 워크플로우를 확정하고, Developer에게 인계하십시오.
*   **인계 지시사항 2 (접근 경로):** 최우선 타겟 기관별 **실제 접근 경로 및 인증 정보 초안 목록**을 확보하고, Developer에게 인계하여 DB 설계 시 필요한 외부 연동 요소(API 엔드포인트 등)를 미리 파악할 수 있도록 지원하십시오.
*   **마감:** SOP 초안 및 접근 경로 목록을 [D-Day + 5일]까지 완료하여 Developer에게 인계하십시오.

## 🤝 공통 지시사항 (모든 담당자 대상)
*   **협업:** 두 분은 상호 간의 진행 상황을 매일 오전 9시까지 공유해야 합니다.
*   **품질:** 설계 및 프로세스 정의 시, **ALTIT KOREA의 브랜드 톤(친근함)과 회사 정체성**에 부합하도록 명확하고 구조화된 형태로 작성해야 합니다.
