# 🚀 [Action Plan] 연구과제 조사 실행 단계 전환 가이드라인

연구과제 조사 데이터 수집 범위 확정 및 DB 스키마 설계 실행 단계로 전환.

## 2. 작업 분배 상세
| 에이전트 | 할당된 핵심 작업 | 마감 기한 (D+N) | 확인 사항 |
| :--- | :--- | :--- | :--- |
| **Researcher** | 최종 데이터 항목 정의서 및 타겟 기관별 접근 경로 확정 | D+1일 | 데이터 항목의 최종 정의서 및 각 기관별 접근 경로 목록 확정. |
| **Developer** | 확정된 데이터 항목 기반의 PostgreSQL DB 스키마 설계 착수 | D+2일 | Researcher가 확정한 데이터 항목을 기반으로 DB 스키마 설계 시작. |

*   **Researcher 대상:** 최종 데이터 항목/경로 확정 마감 **D+1일**을 명확히 공지하고, 이 작업을 최우선으로 진행하도록 지시합니다.
*   **Developer 대상:** DB 스키마 설계 착수 마감 **D+2일**을 명확히 공지하고, Researcher의 결과물을 기반으로 즉시 설계에 착수하도록 지시합니다.
