### 📋 연구과제 데이터 추출 SOP 세부 워크플로우 (Draft V1.1)

이 SOP는 **'데이터 수집 → 데이터 구조화 → 데이터 추출/매핑 → 품질 검증'**의 4단계로 구성됩니다.

#### **Phase 1: 타겟 기관 및 데이터 소스 매핑 (Mapping & Sourcing)**

**목표:** 연구과제 정보를 보유하고 있는 최우선 타겟 기관별로 접근 가능한 모든 경로(API, 웹 크롤링, 공개 데이터 포털 등)를 확정하고, 각 경로의 실현 가능성을 평가합니다.

1.  **타겟 기관 최종 확정 (Input):**
    *   (참조: sessions/2026-05-05T08-59/researcher.md) 확정된 Top 5~10개 정부 부처 및 공공 연구기관 리스트를 기반으로 진행합니다.
2.  **기관별 검색 가이드라인 초안 검토 (Verification):**
    *   (참조: sessions/2026-05-05T08-24/researcher.md) 각 기관별로 정의된 '기관별/분야별 검색 가이드라인 초안'을 검토하여, 실제 접근 가능 여부를 1차적으로 평가합니다.
3.  **접근 경로 상세 정의 (Execution):**
    *   각 기관별로 **실제 데이터 추출을 위한 구체적인 URL, API 엔드포인트, 필요한 인증/인가 방식(필요 시), 크롤링 필요 빈도**를 명시합니다.
    *   *산출물:* **'기관별/분야별 접근 경로 및 실현 가능성 평가 보고서'** (Phase 1 산출물)

#### **Phase 2: 데이터 스키마 및 추출 모듈 설계 (Schema & Module Design)**

**목표:** Phase 1에서 정의된 데이터 항목(컬럼)과 추출 경로를 기반으로, 안정적인 데이터베이스 구조와 추출 모듈의 기술적 요구사항을 최종 확정합니다.

1.  **최종 데이터 컬럼 정의 승인 (Schema Finalization):**
    *   (참조: sessions/2026-05-05T06-54/researcher.md) 최종적으로 확정된 **'Final Scope Document (13개 컬럼)'**을 검토하고, 개발팀(코다리)의 DB 스키마 V2 설계안과 1:1 매핑을 최종 확인합니다.
    *   **핵심 검증:** 'ALTIT 매칭 점수(AMS)' 가중치 적용 로직의 데이터 기반 타당성을 최종 검토하고 확정합니다.
2.  **DB 스키마 V2 및 추출 모듈 로드맵 확정 (Technical Blueprint):**
    *   (참조: sessions/2026-06-03T19-30/developer.md) 코다리가 설계한 PostgreSQL DB 스키마 V2와 데이터 추출 모듈의 기술적 요구사항 명세 초안을 최종 검토하고, **데이터 흐름(Flow) 및 오류 처리 로직(Error Handling)**을 포함하여 상세화합니다.
3.  **데이터 추출 SOP 세부 단계 확정 (Workflow Finalization):**
    *   Phase 1의 경로와 Phase 2의 스키마를 연결하여, **실제 데이터 추출을 위한 'Step-by-Step 워크플로우(SOP)'**를 최종 확정합니다. (예: 기관 A $\rightarrow$ API Call X $\rightarrow$ 데이터 정제 $\rightarrow$ DB INSERT)

#### **Phase 3: 데이터 추출 및 초기 검증 (Extraction & Validation)**

**목표:** 확정된 SOP에 따라 실제 데이터를 수집하고, 데이터의 무결성(Integrity)을 초기 단계에서 검증합니다.

1.  **모듈 구현 지시 (Development Handoff):**
    *   (참조: sessions/2026-06-03T20-45/developer.md) 개발팀에게 Phase 2에서 확정된 기술 요구사항 명세(Schema V2 및 모듈 로드맵)를 기반으로 **데이터 추출 모듈 구현을 시작하도록 지시**합니다.
2.  **Pilot Data Extraction (Testing):**
    *   최소 1개 타겟 기관을 선정하여, Phase 3에서 확정된 SOP를 따라 **Pilot 데이터 추출**을 실행합니다.
3.  **초기 데이터 품질 검증 (Quality Check):**
    *   추출된 데이터가 Phase 2에서 정의한 **Schema V2의 모든 제약 조건(데이터 타입, 필수 필드 포함 여부)**을 충족하는지 검증합니다.

#### **Phase 4: 최종 검증 및 반복 (Final Validation & Iteration)**

**목표:** 데이터 추출 프로세스 전체의 안정성과 정확성을 최종적으로 검증하고, 발견된 문제점을 SOP에 반영하여 반복합니다.

1.  **전체 프로세스 검증 (End-to-End Testing):**
    *   Phase 1부터 Phase 3까지의 모든 단계(Mapping $\rightarrow$ Extraction $\rightarrow$ Validation)를 통합하여 **종합 테스트**를 수행합니다.
2.  **SOP 피드백 및 수정 (Refinement):**
    *   테스트 과정에서 발견된 비효율적인 단계, 접근 불가 경로, 데이터 불일치 지점을 식별하여 **SOP를 즉시 수정**합니다. (이 과정은 Phase 1 또는 Phase 2로 복귀하여 반복될 수 있습니다.)
3.  **최종 산출물 승인 (Sign-off):**
    *   모든 검증이 완료된 SOP 및 데이터 추출 프로세스 정의서를 최종 승인합니다.
