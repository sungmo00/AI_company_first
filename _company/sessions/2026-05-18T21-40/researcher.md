## 📋 실행 계획 (Action Plan)
본 작업은 기존에 진행된 AMS 가중치 로드맵과 데이터 요구사항 명세서(Researcher 개인 메모리 참조)를 기반으로, **'연구과제 채택에 필요한 핵심 데이터 확보'**을 위한 구체적인 실행 계획 및 데이터 소스 확정 작업을 분리하여 진행합니다.

**1단계: 기존 요구사항 명세서 최종 검토 및 실행 계획 수립 (Focus: What & How)**
*   **입력 자료:** Researcher 개인 메모리 내의 'AMS 가중치 로드맵 기반 최종 요구사항 명세서' 및 '데이터 확보 계획'.
*   **수행 내용:**
    1.  **요구사항 명세서 최종 검토:** 현재 정의된 데이터 항목(컬럼), 필요한 데이터의 정확성 및 완전성을 최종 확인합니다.
    2.  **핵심 데이터 확보 실행 계획 구체화:** 각 데이터 항목(Requirement)별로 '어떻게' 데이터를 수집할 것인지에 대한 상세 실행 단계(Step-by-Step Procedure)를 정의합니다. (예: '타겟 기관 A의 연구과제 데이터 수집' $\rightarrow$ [검색어/API 호출 경로] $\rightarrow$ [데이터 정제 로직])
    3.  **우선순위 매트릭스 작성:** 확보해야 할 데이터의 중요도(채택 성공 기여도)와 수집 난이도/비용을 기준으로 우선순위를 재정렬합니다.

**2단계: 데이터 소스 목록 확정 및 1차 탐색 (Focus: Where)**
*   **입력 자료:** Researcher 개인 메모리 내의 '최우선 타겟 5개 정부 및 공공기관의 구체적인 웹/API 접근 경로 초안' 및 '데이터 소스 탐색 전문가 확보를 위한 인력 채용 예산 승인 요청' 관련 정보.
*   **수행 내용:**
    1.  **타겟 기관별 데이터 소스 확정:** 1단계에서 정의된 각 연구과제 유형(예: AI, ICT 등)에 대해, 1차 탐색 리스트에서 가장 실현 가능성이 높은 **최종 데이터 소스(API, 공개 DB, 크롤링 대상 웹사이트)**를 확정합니다.
    2.  **데이터 소스 안정성 평가:** 확정된 각 데이터 소스의 **접근 난이도(Low/Medium/High)**와 **데이터 신뢰도(High/Medium/Low)**를 평가합니다.
    3.  **데이터 수집 전략 초안 작성:** 각 소스별로 데이터 추출 시 발생 가능한 기술적 병목(API 제한, 크롤링 차단 등)에 대한 **대체 전략(Fallback Plan)** 초안을 작성합니다.

**3단계: 실행 계획 산출물 통합 및 공유 (Focus: Deliverable)**
*   **산출물 형태:** 최종 '연구과제 데이터 확보 실행 계획서 (Data Acquisition Roadmap)'
*   **포함 내용:**
    1.  최종 확정된 데이터 요구사항 명세서 (요약본)
    2.  기관별/분야별 데이터 수집 Step-by-Step 가이드라인
    3.  확정된 데이터 소스 목록 및 안정성 평가표 (출처 링크 필수)
    4.  리소스(인력/예산) 요구사항의 세부 항목 (Business 에이전트와 연계 필요)
