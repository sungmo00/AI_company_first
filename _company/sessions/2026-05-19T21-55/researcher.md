### 1. 최종 실행 로드맵 (SOP) 구조 설계

데이터 확보 목표는 **"정부 및 공공기관의 연구과제 데이터베이스로부터 필요한 정보를 체계적으로 추출하고, ALTIT KOREA의 AMS(ALTIT Matching Score) 모델 적용을 위한 데이터를 확보하는 것"**입니다.

| 단계 (Phase) | 목표 (Goal) | 주요 활동 내용 (Key Activities) | 산출물 (Deliverables) | 담당 에이전트 | 완료 기준 |
| :--- | :--- | :--- | :--- | :--- | :--- |

| **Phase 2: 데이터 추출 모듈 개발 및 검증** | 확정된 경로를 통해 실제 데이터를 안정적으로 수집하는 기술적 모듈 구현 및 초기 검증 | 1. 데이터 추출 모듈(API/크롤링) 인터페이스 정의 및 초기 구현 (Developer 협업). 2. 데이터 정제(Cleaning) 로직 설계. 3. **AMS 가중치 적용 로직의 데이터 기반 타당성 검토 및 확정.** | 초기 데이터 추출 모듈 (API Endpoint 명세 포함), AMS 가중치 적용 로직 상세 기준서. | Developer/Researcher | 데이터 추출 모듈 시뮬레이션 성공 및 AMS 가중치 기준서 승인. |
| **Phase 3: 데이터 확보 및 초기 검증 (PoC)** | 실제 데이터 수집을 통한 로드맵의 실효성 및 기술적 안정성 검증 | 1. 확정된 경로를 이용한 실제 데이터 수집 실행 (Pilot Run). 2. 수집된 데이터의 무결성(Integrity) 및 양(Volume) 검증. 3. 수집된 데이터의 AMS 모델 입력 적합성 테스트. | PoC 결과 보고서 (데이터 수집 성공률, 지연 시간, 데이터 품질 평가), 최종 SOP/로드맵 확정본. | Researcher | PoC 보고서 제출 및 로드맵의 기술적 실효성 최종 승인. |

### 2. 단계별 데이터 소스 접근 경로 (초안) 및 PoC 계획

**[Phase 1 상세: 데이터 소스 접근 경로 확정]**

| 타겟 기관 그룹 | 세부 타겟 (예시) | 데이터 유형 (예상) | 접근 경로 초안 (Researcher 메모리 기반) | PoC 계획 (실효성 테스트) |
| :--- | :--- | :--- | :--- | :--- |
| **Tier 1: 정부 부처** | 과학기술정보통신부, 산업통상자원부 등 | 국가 R&D 과제 DB, 정책 자료 | 1. 공식 공지사항 API (검색어 기반). 2. 정부 포털 내 검색 엔진 활용 시나리오. | **[Test A]** 특정 키워드(예: 'AI', '첨단기술')를 입력하여 데이터 수집 성공률 측정. (성공률 > 70% 목표) |
| **Tier 2: 공공 연구기관** | KIST, ETRI 등 | 개별 연구과제 상세 정보, 기술 보고서 | 1. 기관별 연구정보 게시판 크롤링 시나리오. 2. 기관별 공개 데이터 포털 API 탐색. | **[Test B]** 비정형 데이터(보고서) 추출의 복잡도 측정. (추출 정확도 > 85% 목표) |
| **Tier 3: 기타/특화 기관** | 산학연협력센터, 특정 재단 등 | 비공식/부분 공개된 과제 정보 | 1. 관계자 네트워크 분석을 통한 비공식 채널 탐색 가이드라인. 2. 협력 기관 공통 데이터 포털 확인. | **[Test C]** 비공식 채널 확보의 난이도 및 예상 리소스(인력/예산) 산출. |

**[Phase 2 상세: 데이터 추출 모듈 개발 및 검증]**

*   **핵심 작업:** Developer가 정의한 `ResearchProjectSchema`를 기반으로, Phase 1에서 확정된 각 경로에 맞는 맞춤형 추출 모듈(API 호출, 선택적 크롤링)을 구현합니다.
*   **AMS 가중치 적용 검증:** 이 단계에서 **"ALTIT 매칭 점수(AMS) 가중치 적용 로직의 데이터 기반 타당성"**을 검토합니다.
    *   **검토 기준:** 추출된 데이터 항목(Column)이 AMS 모델의 입력 변수로 사용될 때, 각 변수의 정규화 및 가중치 할당이 비즈니스 목표(정부 과제 채택 확률)에 얼마나 기여하는지 통계적/논리적으로 검증합니다.
    *   **산출물:** AMS 가중치 적용 로직 상세 기준서 (데이터 기반 타당성 검토 완료).

**[Phase 3 상세: 데이터 확보 및 초기 검증 (PoC)]**

*   **목표:** Phase 1과 2에서 설계된 모든 경로와 모듈이 통합적으로 작동하는지 확인합니다.
*   **PoC 시나리오:** 실제 데이터 수집(Pilot Run)을 수행하며, **데이터 흐름의 안정성**과 **수집된 데이터의 품질(정확성, 완전성)**을 측정합니다.
*   **결과 산출물:** **PoC 결과 보고서**는 다음 주차에 전체 로드맵의 최종 승인 근거가 됩니다.
