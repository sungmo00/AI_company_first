# 검증 데이터 요청 프롬프트 (MVP Validation Request)

**역할:** Researcher 에이전트 (데이터 수집 및 검증 담당)

**목표:** ALTIT KOREA가 설계한 수익화 모델(가격/번들 옵션)의 시장 수용성 및 ROI 예측 정확도를 검증하기 위해, 경쟁사 및 잠재 고객 반응 데이터를 수집하도록 요청한다.

**배경:**
우리는 [수익화 모델 1안]의 가격/번들 구조(A, B, C 옵션)와 이에 따른 경쟁사별 예상 ROI 분석 프레임워크를 확정했습니다. 이제 이 가설을 현실의 데이터로 검증해야 합니다.

**요청 사항:**
아래 세 가지 핵심 가설을 검증하기 위해, 다음 유형의 데이터를 수집하고 정리해 주십시오.

**1. 가격 민감도 데이터 (Price Sensitivity Data)**
*   **목표:** 각 번들 옵션(A, B, C)에 대해 잠재 고객이 실제로 지불 의사가 있는 가격대와 그에 따른 전환율을 파악합니다.
*   **요청 데이터 예시:**
    *   경쟁사 X의 유사 서비스에 대한 가격대별(예: $X, $Y, $Z) 전환율 데이터.
    *   우리 모델의 옵션 A/B/C에 대한 **가상 시나리오 기반 설문 응답** (예: "이 가격대에서 구독할 의향이 있습니까? [Y/N]").

**2. 가치 제안 적합성 데이터 (Value Proposition Fit Data)**
*   **목표:** 우리 모델이 제시하는 핵심 가치(정부 과제 지원 연계 등)가 타겟 청중에게 얼마나 매력적으로 인식되는지 측정합니다.
*   **요청 데이터 예시:**
    *   경쟁사 Y의 서비스에 대한 **'가장 매력적인 기능 3가지'** 및 해당 기능에 부여한 가치 점수.
    *   타겟 청중이 '정부 과제 연계'라는 가치에 부여하는 **주관적 중요도 점수**.

**3. ROI 예측 변수 데이터 (ROI Predictor Variables)**
*   **목표:** 우리의 ROI 분석 프레임워크의 핵심 변수(예: 정부 지원금 확보 확률, 제안서 품질 점수)가 실제 성과에 미치는 영향을 예측하기 위한 변수를 수집합니다.
*   **요청 데이터 예시:**
    *   과거 유사 프로젝트의 **'제안서 품질 점수(1-10점)'**와 최종 채택 성공률 간의 상관관계 데이터.
    *   리소스 투입(인력/예산) 대비 **'성공률 변화 예측치'**에 대한 정량적 데이터.

**산출물 형식:**
수집된 모든 데이터는 다음 구조로 정리되어야 합니다. (CSV 또는 JSON 형식 선호)
```json
{
  "data_source": "경쟁사 X / 설문 응답 / 내부 예측",
  "validation_set": "옵션 B",
  "metric_type": "Price Sensitivity",
  "value": {
    "price_tier": "$Y",
    "conversion_rate": "15%"
  },
  "contextual_insight": "해당 가격대에서 전환율이 높게 나타남."
}
```

**후속 조치:**
데이터 수집 완료 후, Researcher 에이전트는 이 데이터를 바탕으로 **'검증 결과 요약 보고서'**를 작성해야 합니다.

---
**Business 에이전트 코멘트:** 이 프롬프트는 데이터 요청의 목적(가설 검증)과 원하는 데이터 형식(구조화된 JSON)을 명확히 하여, Researcher가 수집해야 할 데이터의 품질과 우리가 분석할 수 있는 용이성을 극대화합니다. 이 프롬프트를 기반으로 데이터 요청을 시작하십시오.
