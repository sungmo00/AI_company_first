## 📊 데이터 추출 프로세스 정의서(SOP) 초안 작성 및 워크플로우 구체화

**목표:** Researcher의 검토 의견과 Developer의 모듈 초안을 종합하여, '정부 및 공공기관 연구과제 조사'를 위한 데이터 추출 프로세스(수집, 정제, 매핑)의 상세 워크플로우를 확정하는 초안을 작성합니다.

**참조 자료:**
1.  Researcher의 최종 컬럼 정의서 (승인 완료됨)
2.  Developer의 데이터 추출 모듈 초안 (검토 요청 및 피드백 반영 단계)
3.  (참고) Researcher의 AMS 가중치 관련 피드백 (Researcher 산출물 참조)

### 1단계: 데이터 추출 프로세스 워크플로우 (초안)

**단계 1.1: 환경 및 접근 경로 확정 (Researcher 주도)**
*   **목표:** 최우선 타겟 5개 기관의 API/웹 접근 경로를 최종 확정하고, 필요한 인증 정보(API Key 등)를 확보합니다.
*   **세부 활동:**
    *   확정된 타겟 기관별 웹 크롤링/API 호출 방식 결정.
    *   접근 경로의 안정성 및 지속 가능성 검증 (Rate Limiting, 변경 가능성 분석).
    *   **산출물:** 최종 확정된 기관별 접근 경로 목록 및 인증 정보(보안 처리 필요).

**단계 1.2: 데이터 수집 (Developer 주도)**
*   **목표:** 확정된 접근 경로를 기반으로 연구과제 관련 원천 데이터를 수집합니다.
*   **세부 활동:**
    *   각 기관별 맞춤형 데이터 요청 쿼리/스크립트 개발.
    *   비정형 데이터(HTML 파싱, JSON 응답)를 정형화된 초기 데이터 구조로 추출.
    *   **산출물:** 원시(Raw) 데이터 셋 (기관별/형식별 분리).

**단계 1.3: 데이터 정제 및 표준화 (Secretary 주도)**
*   **목표:** 수집된 원시 데이터를 Researcher가 정의한 최종 컬럼 정의서(13개 항목 + 관계성 필드)에 맞게 정제하고 표준화합니다.
*   **세부 활동:**
    *   데이터 형식 변환 (날짜, 숫자, 텍스트 정규화).
    *   **ALTIT 매칭 점수(AMS) 계산을 위한 기초 데이터 준비:** 각 필드별로 AMS 가중치 적용에 필요한 입력 변수 추출 및 정규화.
    *   데이터 무결성 검사 (누락된 필수 항목 체크).
    *   **산출물:** 정제 완료된 데이터셋 (SOP 단계별 중간 산출물).

**단계 1.4: 데이터 매핑 및 최종 검증 (Developer/Researcher 협업)**
*   **목표:** 정제된 데이터를 최종 분석 및 시스템 활용에 적합하도록 매핑하고, AMS 가중치를 최종 적용합니다.
*   **세부 활동:**
    *   데이터 간의 관계성 필드 연결 (관계성 필드 정의에 따라).
    *   **AMS 가중치 적용 로직 실행:** 단계 1.3에서 준비된 입력 변수를 활용하여 AMS 점수 계산 모듈 실행.
    *   최종 검증: 생성된 데이터의 품질(Completeness, Accuracy)이 목표치에 도달했는지 확인.
    *   **산출물:** 최종 분석 및 활용 가능한 연구과제 데이터셋 (최종 산출물).

### 2단계: 워크플로우 상세화 및 다음 액션 분배

| 단계 | 주요 책임 에이전트 | 핵심 작업 내용 | 완료 조건 (Gate) |
| :--- | :--- | :--- | :--- |
| 1.1 | Researcher | 최종 접근 경로 및 인증 정보 확정 | 타겟 기관별 접근 경로 목록 제출 |
| 1.2 | Developer | 수집 스크립트 구현 및 테스트 | 원시 데이터 추출 기능 성공적 완료 |
| 1.3 | Secretary | 데이터 정제 및 표준화 로직 구현 | 정제된 중간 데이터셋 생성 완료 |
| 1.4 | Developer/Researcher | AMS 가중치 적용 및 최종 매핑 | 최종 분석 데이터셋 생성 완료 (목표 충족) |

**분배 계획:**
*   **Researcher:** 단계 1.1에 집중하여 **'데이터 수집의 기반(인프라)'**을 확정합니다.
*   **Developer:** 단계 1.2와 1.4의 핵심 로직(수집 모듈 및 AMS 계산 모듈)을 구현하는 데 집중합니다.
*   **Secretary:** 단계 1.3의 **'데이터 품질 관리 및 표준화(Quality Control)'** 프로세스를 설계하고 구현하는 데 집중합니다.
