# 📋 작업 브리프

**원 명령:** [수동 한 스텝 — CEO] CEO 에이전트의 개인 목표(_agents/ceo/goal.md)를 향해 다음 한 스텝을 실행하세요. 반드시 ceo 에이전트에게 작업을 분배하세요.

## 요약
CEO의 개인 목표 달성을 위해, 현재 진행 중인 연구과제 조사 및 데이터 추출 프로세스 정의서(SOP) 확정 작업을 위한 다음 단계를 지시합니다.

## 분배
- **🔍 Researcher**: Developer가 작성한 데이터 추출 모듈 초안에 대한 최종 승인(Accept) 또는 수정 요청 의견을 즉시 제공하여 데이터 구조의 확정 작업을 완료할 수 있도록 상세 피드백을 준비합니다. 특히, 'ALTIT 매칭 점수(AMS)' 가중치 적용 로직의 데이터 기반 타당성을 최종 검토하고 확정해야 합니다.
- **📱 Secretary**: Researcher의 검토 의견과 Developer의 모듈 초안을 취합하여, 최종 데이터 추출 프로세스 정의서(SOP)의 워크플로우를 구체화하는 작업을 시작합니다. Researcher와 협력하여 최종 SOP에 포함될 데이터 추출 단계(수집, 정제, 매핑)의 상세한 워크플로우를 초안으로 작성합니다.
