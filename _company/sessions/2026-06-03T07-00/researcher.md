### 1단계: 연구과제별 필수 데이터 요구사항 (Schema & Mapping) 최종 확정

이 단계에서는 '연구과제 조사'라는 목표 달성에 필요한 모든 정보를 구조화된 필드(컬럼)로 정의하고, 각 필드가 어떤 종류의 데이터를 포함해야 하는지 명확히 매핑합니다.

**[산출물: 연구과제 데이터 요구사항 최종 정의서 (Schema & Mapping)]**

이 문서는 Researcher의 개인 메모리에서 수집된 요구사항(13개 컬럼 정의)과 Developer가 설계한 Pydantic 스키마(`ResearchProjectSchema`)의 매핑을 최종적으로 검토하고 확정하는 과정입니다.

**핵심 정의:** 연구과제 데이터는 크게 **'식별 정보', '연구 내용 상세', '지원/평가 정보', '연관성 분석'** 네 가지 카테고리로 분류됩니다.

| 카테고리 | 필수 컬럼 (Field Name) | 데이터 타입 (Type) | 설명 및 추출 로직 상세 | 중요도 | 비고 (출처/제약사항) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **식별 정보** | `project_id` | String | 연구과제 고유 식별자 (기관 부여) | 필수 | 기관별로 상이할 수 있음. 추출 시 기관명 기반 조합 필요. |
| | `title` | String | 연구과제 전체 제목 | 필수 | 정형화된 텍스트 추출. |
| | `funding_source` | String | 연구 과제를 지원한 정부 부처/기관 (예: 과기정통부, 산업부) | 필수 | 기관 분류를 통해 정규화 필요. |
| | `submission_date` | Date | 연구과제 제출일 또는 공고일 | 높음 | 시계열 분석을 위해 필수. |
| **연구 내용 상세** | `abstract` | Text | 연구과제의 핵심 요약 (최대 500자) | 필수 | NLP를 통한 키워드 추출이 필요함. |
| | `keywords` | List[String] | 연구과제 관련 핵심 키워드 (최대 5개) | 높음 | 메타데이터 추출. |
| | `research_focus` | String | 연구의 핵심 기술/분야 (예: AI, 양자 컴퓨팅, 바이오) | 필수 | **(Researcher 핵심)** 해당 분야 매핑 프레임워크와 직접 연결됨. |
| | `methodology` | Text | 연구 수행 방법론 (예: 실험 설계, 시뮬레이션 모델 등) | 높음 | 기술적 난이도 분석에 사용. |
| **지원/평가 정보** | `status` | String | 현재 연구과제 상태 (예: 선정, 보완 중, 최종 통보) | 필수 | 진행 상황 추적에 중요. |
| | `budget_amount` | Integer/Float | 연구비 규모 (단위 명시 필수) | 높음 | 재정적 타당성 분석의 핵심 변수. |
| | `evaluation_score` | Float | 평가 점수 또는 등급 (1~5점 척도) | 높음 | 경쟁사 ROI 분석의 핵심 입력 변수. |
| **연관성 분석** | `relevance_score` | Float | 우리 회사/기술과의 관련성 점수 (0.0 ~ 1.0) | 필수 | **(ALTIT 매칭 점수, AMS)** Developer가 설계한 로직의 핵심. |
| | `suitability_reason` | Text | 해당 과제가 우리 회사 기술/역량과 부합하는 이유 분석 | 높음 | 데이터 기반의 '맞춤형 제안' 근거 생성. |

**[검토 및 확정]**
위 13개 필드는 **'연구과제 조사' 목표 달성**에 필요한 모든 정보를 포괄합니다. 특히 `research_focus`, `evaluation_score`, `relevance_score`는 향후 **수익화 모델(Business 에이전트 영역)**과 직접 연결될 핵심 변수입니다.
