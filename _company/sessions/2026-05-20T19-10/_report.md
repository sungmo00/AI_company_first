### 📝 CEO 보고용: 다음 단계 실행 로드맵 (Action Plan) 초안

**📌 핵심 요약:** 현재 연구과제 조사 로드맵의 **SOP 최종 확정**이 최우선 과제입니다. 이 작업이 완료되는 즉시, DB 설계와 데이터 추출 모듈 구현을 병렬로 가속화해야 합니다.

#### ✅ 1순위 과제: 연구과제 조사 SOP 최종 확정 (Researcher 주도)

*   **목표:** 연구과제 조사 로드맵 실행 SOP의 최종 확정 및 단계별 데이터 추출/검증 기준 정의 완료.
*   **담당 에이전트:** Researcher (주요), Developer (보조 검토)
*   **핵심 산출물:** 최종 확정된 SOP 및 데이터 추출/검증 기준 명세서.
*   **필요 조치:**
    1.  Researcher가 Phase 1, 2, 3 단계별 데이터 추출/검증 기준을 구체화하여 최종 보고 완료.
    2.  Developer는 확정될 SOP 구조를 기반으로 DB 설계 착수 준비(초기 인터페이스 정의 반영) 완료.

#### 🛠️ 후속 과제 A: PostgreSQL DB 스키마 설계 착수 (Developer 주도)

*   **목표:** 확정된 SOP 기반의 PostgreSQL 데이터베이스 스키마 설계 착수.
*   **담당 에이전트:** Developer
*   **핵심 산출물:** Phase 1, 2, 3 단계에 필요한 테이블 구조를 확정한 DB 스키마 초안.
*   **필요 조치:** Researcher가 정의한 데이터 요구사항(Phase 1 기준)을 즉시 반영하여 스키마 설계 착수.

#### ⚙️ 후속 과제 B: 데이터 추출 모듈 구현 준비 (Secretary 주도)

*   **목표:** SOP 확정 후, 데이터 추출 모듈 구현 상세 실행 계획 수립 및 기술 리소스 검토.
*   **담당 에이전트:** Secretary
*   **핵심 산출물:** 데이터 추출 프로세스 정의서(SOP 상세 워크플로우) 확정 및 개발팀 분배 계획.
*   **필요 조치:** SOP 최종본을 수신하는 즉시, 데이터 추출 단계별 워크플로우를 구체화하고 개발팀에게 Task Breakdown 분배.

2.  **Developer:** Researcher의 SOP 초안 검토 및 DB 설계 착수 준비를 위한 초기 인터페이스 정의 반영 완료.
