### 📄 연구과제 조사 실행 로드맵 (v1.0) 현실성 검토 보고서 초안

**작성일:** 2026-05-10
**분석 대상:** Secretary 작성 '연구과제 조사 실행 로드맵 (v1.0)' 초안
**분석 목적:** 데이터 수집 및 접근 경로의 현실성 검토, 구체적인 데이터 요구사항 제시

#### 1. 로드맵 구조적 완성도 검토 (Structural Review)

| 단계 | 목표 요약 (초안 기반) | 현실성 평가 (Researcher 관점) | 개선/확인 필요 사항 |
| :--- | :--- | :--- | :--- |
| **Phase 1: 접근 경로 확보** | 최우선 타겟 기관 리스트 확정 및 데이터 수집을 위한 초기 접근 경로(API/웹) 확보. | **중간 수준.** 타겟 기관 리스트는 확정되었으나, '비공식 채널 확보'의 구체적인 정의와 실행 계획이 부족함. API/웹 접근 경로 초안은 있으나, 실제 크롤링/API 호출 시의 **에러 핸들링 전략**이 누락됨. | 각 타겟 기관별로 'API 실패 시 대체 데이터 수집 전략(Fallback Plan)' 정의 필요. |
| **Phase 2: 핵심 모듈 구현** | 데이터 추출 모듈의 인터페이스 정의(API Endpoint 명세) 및 초기 기술적 모듈 구현. | **고난도.** 데이터 추출 시, 기관별로 상이한 데이터 포맷(JSON/XML 등)을 일괄적으로 처리할 수 있는 **유연한 파싱 모듈** 설계가 핵심 과제임. | 데이터 포맷의 비일관성(Inconsistency)을 고려한 **Adapter Pattern** 적용 여부를 명시적으로 설계 단계에 포함해야 함. |
| **Phase 3: 리소스 및 비용 확정** | 연구과제 데이터베이스(Schema) 정의 완료 및 리소스 투입 우선순위 확정. | **잠재적 병목.** 데이터 수집(Phase 1, 2)의 불확실성이 높기 때문에, 이 단계에서 리소스를 확정하면 실제 데이터 수집 실패 시 **전체 로드맵 재작업**이 불가피함. | Phase 1, 2의 데이터 수집 성공률(Success Rate)에 따른 **조건부 리소스 배분 모델**을 도입해야 함. |

#### 2. 단계별 데이터 요구사항 및 품질 기준 정의 (Data Requirements)

| 단계 | 필요한 핵심 데이터 항목 (Schema 예시) | 요구 품질 기준 (Researcher 관점) | 비고/위험 요소 |
| :--- | :--- | :--- | :--- |
| **Phase 1** | 기관 식별자, 공개 API 엔드포인트, 데이터 업데이트 주기, 접근 난이도 점수. | **정확성(Accuracy):** 기관/경로 정보의 100% 검증 필요. **최신성(Recency):** 최소 6개월 이내 업데이트된 정보만 포함. | 비공식 채널 확보 시, 데이터의 **신뢰도(Trustworthiness)**가 급격히 하락할 수 있음. |
| **Phase 2** | Raw Data (기관별로 상이한 포맷), 데이터 정제(Cleaning) 필요 항목, 파싱 성공률. | **완결성(Completeness):** 누락된 필드 없이 모든 필수 항목을 추출해야 함. **일관성(Consistency):** 데이터 타입 및 형식의 통일성 확보가 필수적. | 다양한 소스에서 들어오는 데이터의 **노이즈(Noise)** 수준이 높을 것으로 예상됨. |
| **Phase 3** | 최종 데이터베이스 스키마(Final Schema), 데이터 품질 지표(DQ Metrics), 예상 리소스(인력/비용). | **실행 가능성(Feasibility):** 정의된 스키마가 실제 DB 구축 및 분석에 즉시 사용 가능해야 함. | 데이터 추출 난이도(Complexity Score)가 높을 경우, **예산 초과 위험**이 명확함. |

#### 3. 실행 가능성 진단 및 권고 사항 (Feasibility Verdict & Recommendations)

*   **가장 큰 위험:** Phase 1에서 '비공식 채널' 확보에 과도한 리소스를 투입하여, Phase 2의 데이터 추출 모듈 설계가 지연되는 것입니다.
*   **Researcher 권고:** Phase 1의 비공식 채널 확보를 **'최소한의 탐색적 조사(Exploratory Investigation)'** 수준으로 제한하고, **'정식 API/공개 데이터 확보(Structured Data Acquisition)'**에 리소스의 70% 이상을 투입하도록 우선순위를 재조정할 것을 제안합니다.
*   **다음 단계 준비:** Phase 2로 넘어가기 전에, **가장 핵심적인 데이터 항목(Minimum Viable Data Set)**을 정의하여 Phase 1의 목표를 구체화해야 합니다.
