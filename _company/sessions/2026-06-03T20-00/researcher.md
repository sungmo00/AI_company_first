CEO의 지시에 따라, 정부 및 공공기관 연구과제 조사를 위한 '데이터 추출 프로세스 정의서(SOP)'의 세부 단계 및 워크플로우를 최종 확정하고, 수집-정제-매핑 단계를 포함한 구체적인 실행 계획을 작성하겠습니다. 이는 **최우선 과제**이며, Researcher 개인 메모리 및 이전 로그에서 확정된 목표(정부/공공기관 연구과제 조사)에 기반하여 설계됩니다.

이 작업은 **'데이터 추출 프로세스 정의서(SOP)'**의 최종 확정을 목표로 하며, 나아가 이 SOP를 기반으로 데이터 파이프라인 구축의 청사진을 제공해야 합니다.

### 1단계: SOP 최종 확정 목표 및 범위 정의 (Researcher 메모리 기반)

이 단계에서는 **무엇을, 어디서, 어떻게** 수집할 것인지의 구조적 프레임워크를 확정합니다.

1.  **타겟 범위 확정:** CEO의 목표에 부합하도록, '최우선 타겟 5개 기관'의 데이터 수집 전략을 구체화합니다.
2.  **데이터 항목 정의 (Schema Finalization):** Researcher 개인 메모리에서 확정된 최종 컬럼 정의서(Final Scope Document)를 기반으로, 데이터 추출의 정확성을 보장할 최종 스키마를 확정합니다.
3.  **수집 경로 정의 (Acquisition Strategy):** 각 타겟 기관별로 가장 효율적이고 안정적인 데이터 획득 경로(API, 웹 크롤링, 공공 데이터 포털 등)를 매핑합니다.
4.  **데이터 정제/매핑 로직 정의 (Processing & Mapping):** 수집된 비정형 데이터를 최종 분석 가능한 형태로 변환하기 위한 정제 규칙과, ALTIT KOREA의 핵심 경쟁력인 'ALTIT 매칭 점수(AMS)' 적용 로직을 구체화합니다.

### 2단계: 데이터 추출 프로세스 정의서 (SOP) 상세 워크플로우

아래는 **수집(Collection) $\rightarrow$ 정제(Refinement) $\rightarrow$ 매핑(Mapping)**의 3단계로 구성된 상세 워크플로우입니다.

#### **Phase 1: 데이터 수집 (Collection)**

**목표:** 정의된 타겟 기관으로부터 필요한 원천 데이터를 안정적으로 확보합니다.

| 단계 | 세부 활동 (Task) | 담당/협업 에이전트 | 산출물 (Output) | 성공 기준 (Success Criteria) |
| :--- | :--- | :--- | :--- | :--- |
| **1.1 타겟 기관별 접근 경로 검증** | 확정된 Top 5 기관별로 API 엔드포인트, 웹 크롤링 정책, 데이터 공개 여부(공개/비공개), 요청 주기 등을 **실제 테스트**하여 안정성을 평가합니다. | Researcher (실행) + Developer (기술 검토) | 기관별 데이터 수집 가능성 평가 리포트 | 최소 3개 이상의 경로에서 데이터 추출 성공률 70% 이상 달성. |
| **1.2 데이터 추출 모듈 설계** | 각 경로별로 데이터를 수집할 수 있는 기술적 모듈(Python 기반)의 초기 설계 및 DB 스키마 매핑을 진행합니다. | Developer | 데이터 추출 모듈 초안 (Schema V2 반영) | DB 스키마(PostgreSQL)와의 1:1 매핑 완료. |
| **1.3 데이터 수집 실행** | 확정된 경로에 따라 자동화된 데이터 추출 스크립트를 배포하고, 초기 대량 데이터 수집을 실행합니다. | Developer | 원천 데이터 파일 (Raw Data Dump) | 목표 기간 동안 필요한 최소 데이터셋 확보 완료. |

#### **Phase 2: 데이터 정제 (Refinement)**

**목표:** 수집된 원천 데이터를 분석 및 매핑에 적합한 표준화된 형식으로 변환하고 오류를 수정합니다.

| 단계 | 세부 활동 (Task) | 담당/협업 에이전트 | 산출물 (Output) | 성공 기준 (Success Criteria) |
| :--- | :--- | :--- | :--- | :--- |
| **2.1 데이터 정규화 (Normalization)** | 수집된 텍스트/JSON 데이터를 표준화된 형식(예: JSON, CSV)으로 변환합니다. 누락되거나 비정형화된 필드를 보완합니다. | Developer | 정제된 데이터셋 (Normalized Data) | 데이터 무결성 검사 통과 (Null 값 최소화). |
| **2.2 데이터 품질 검증 (QA)** | 정의된 최종 컬럼(Schema V2)과 비교하여 데이터 타입, 형식의 일관성을 검증합니다. 이상치(Outlier) 탐지 및 처리 규칙을 적용합니다. | Researcher (QA) | 데이터 품질 보고서 (Data Quality Report) | 데이터 정제 기준 충족. 오류 발생률 5% 미만 유지. |
| **2.3 ALTIT 매칭 가중치 적용 준비** | 연구과제의 'Relevance'를 측정할 수 있도록, 각 데이터 항목에 대한 초기 가중치(Weight) 할당 로직을 설계합니다. | Researcher | AMS 가중치 초안 (Weighting Draft) | 매핑 로직에 사용할 초기 가중치 모델(Rule Set) 정의. |

#### **Phase 3: 데이터 매핑 및 분석 (Mapping & Analysis)**

**목표:** 정제된 데이터를 기반으로 ALTIT KOREA의 핵심 경쟁력인 '매칭 점수(AMS)'를 산출하고, 연구과제 제안 전략을 수립합니다.

| 단계 | 세부 활동 (Task) | 담당/협업 에이전트 | 산출물 (Output) | 성공 기준 (Success Criteria) |
| :--- | :--- | :--- | :--- | :--- |
| **3.1 매핑 로직 구현** | Phase 2에서 정의된 가중치와 타겟 기관별 특성(매핑 프레임워크)을 적용하여, 각 연구과제에 대한 종합적인 **ALTIT 매칭 점수(AMS)**를 계산하는 알고리즘을 구현합니다. | Developer | AMS 계산 모듈 (Core Logic) | AMS 산출 결과가 논리적 일관성을 가짐. |
| **3.2 최종 매핑 결과 생성** | AMS 점수와 함께, 해당 과제가 타겟 기관의 요구사항(Needs)에 얼마나 부합하는지를 분석하여 최종 평가 레벨을 부여합니다. | Researcher | 최종 매핑 결과 리포트 (Ranked List) | 타겟 기관별/분야별로 정렬된 연구과제 리스트 완성. |
| **3.3 전략적 제안서 초안 작성** | 최종 매핑 결과를 바탕으로, 연구과제 채택을 위한 맞춤형 제안서의 핵심 스토리라인(Narrative Draft) 초안을 작성합니다. | Researcher (콘텐츠 기획) | 연구과제 제안서 전략 초안 | 제안서의 논리적 흐름(Problem-Solution)이 명확함. |
