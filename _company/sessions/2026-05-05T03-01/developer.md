## 📝 초기 데이터 파이프라인 설계 초안 (Researcher 지시사항 반영)

CEO의 지시에 따라, Researcher가 정의한 13개 컬럼 구조를 기반으로 데이터 수집 및 정제 프로세스를 위한 초기 데이터 파이프라인 설계 초안을 작성합니다. 이 설계는 **수집(Extraction) $\rightarrow$ 정제(Transformation) $\rightarrow$ 저장/분석(Loading/Analysis)**의 3단계 파이프라인을 목표로 합니다.

### 1단계: 데이터 추출 (Extraction) - 소스 확보 전략

**목표:** 정부 및 공공기관의 연구과제 정보를 체계적으로 수집할 수 있는 안정적인 소스 목록을 확정하고, 각 소스별 추출 메커니즘을 설계합니다.

| 단계 | 세부 활동 | 사용 기술/도구 (초안) | 산출물 형태 | 위험 요소 및 완화 전략 |
| :--- | :--- | :--- | :--- | :--- |
| **1.1 소스 식별** | NTIS, 각 부처 R&D 지원 시스템(예: 과기정통부), 출연(연) 홈페이지, 정부 공공 데이터 포털 등 핵심 검색 포털 식별. | 웹 크롤링 프레임워크 (Scrapy/BeautifulSoup) | 소스 URL 목록 및 검색 API 엔드포인트 정의서 | **위험:** 웹사이트 구조 변경. **완화:** 정기적인 소스 검증 로직 및 Fallback 검색 엔진 마련. |
| **1.2 데이터 추출** | 식별된 소스에 대해 키워드 기반 검색 쿼리 설계 및 반복 실행. | Python (Requests, BeautifulSoup) 또는 공식 API 연동 | 원시(Raw) 데이터 JSON/HTML 파일 | **위험:** 동적 콘텐츠 로딩 문제. **완화:** Headless Browser (Selenium) 사용을 예외적으로 도입하고, 추출 실패 시 로그 기록. |
| **1.3 데이터 정규화** | 수집된 다양한 형식의 데이터를 일관된 JSON/CSV 포맷으로 변환. | Python (Pandas) | 정규화된 데이터셋 (JSON/CSV) | **위험:** 비정형 데이터 처리 오류. **완화:** Pandas의 강력한 데이터 타입 검증 및 예외 처리 블록 구현. |

### 2단계: 데이터 정제 (Transformation) - 품질 관리 프로세스

**목표:** Researcher가 정의한 13개 컬럼 구조를 충족시키고, 품질 관리 기준(Quality Gate)을 적용하여 최종 보고서에 사용될 데이터의 신뢰도를 확보합니다.

| 단계 | 세부 활동 | 적용 기준 (Researcher 피드백 반영) | 사용 기술/도구 (초안) | 산출물 형태 |
| :--- | :--- | :--- | :--- | :--- |
| **2.1 컬럼 매핑** | 추출된 원시 데이터의 필드와 엑셀 필수 컬럼(13개) 간의 매핑 규칙 정의. | **필수 컬럼 13개 구조 준수.** (특히, 연구비 규모, 상태 분류) | Python Dictionary/Schema 정의 파일 | 매핑 맵 (Mapping Map) |
| **2.2 품질 필터링** | 수집된 데이터에 대해 '기관 적합성(80% 이상)' 및 '분야 세분화' 기준에 따라 점수/플래그 부여. | **품질 관리 기준 적용:** 기관 적합성, 분야 세분화 정도 기반 필터링. | Python (Pandas, Custom Scoring Function) | 품질 점수(Score) 컬럼 추가된 데이터셋 |
| **2.3 요약 및 태깅** | '주요 연구 내용 요약' (3줄) 및 '관련 키워드' 자동 생성. | **요약 알고리즘:** TF-IDF 또는 LLM 기반 텍스트 임베딩을 활용한 핵심 문장 추출. | LLM API (예: OpenAI/Gemini) 또는 NLTK 기반 요약 모듈 | 요약 텍스트 및 키워드 컬럼 채워진 데이터셋 |

### 3단계: 데이터 로딩 및 분석 (Loading & Analysis) - 리포트 생성

**목표:** 정제된 데이터를 기반으로 최종 요구사항인 '의사결정 지원 리포트'를 생성합니다.

| 단계 | 세부 활동 | 적용 기준 (CEO 목표 반영) | 사용 기술/도구 (초안) | 산출물 형태 |
| :--- | :--- | :--- | :--- | :--- |
| **3.1 데이터 통합** | 정제된 데이터를 최종 엑셀 형식(13개 컬럼)으로 변환. | **컬럼 구조 준수 확인.** (ID, 명칭, 기관 등 필수 항목 누락 방지) | Pandas $\rightarrow$ `to_excel()` | 최종 엑셀 리포트 파일 (.xlsx) |
| **3.2 분석 지표 생성** | '연구 분야별 분포 분석' 및 '기관별 기회 매핑'을 위한 집계 통계 수행. | **분석 목표 충족:** 분야별 빈도수, 연구비 규모 집계 통계 생성. | Pandas (Groupby, Aggregate) | 분석 결과 요약 테이블 및 시각화 데이터 (JSON/CSV) |
| **3.3 리포트 산출** | 생성된 데이터와 분석 결과를 결합하여 최종 보고서 구조 완성. | **최종 산출물 검토:** 리포트가 제안서 작성에 바로 활용 가능한 형태로 구성되었는지 확인. | Python (Pandas, OpenPyXL) | **최종 연구과제 분석 리포트** |

### 🛠️ 초기 파이프라인 실행 계획 (Actionable Steps)

2.  **[Developer]**: 2단계(데이터 정제)의 **컬럼 매핑 맵 초안**을 상세하게 작성하여 Researcher에게 제공합니다. (특히, '과제 유형' 분류 체계 정의)
3.  **[Researcher]**: 1단계에서 수집된 초기 데이터 샘플을 제공하면, 2단계의 **품질 필터링 로직(2.2)** 구현을 시작합니다.
