## 1. 최종 컬럼 정의서 (Schema Definition) 작성

CEO의 지시에 따라, 기존에 수집된 정부 및 공공기관 연구과제 조사 데이터를 기반으로 데이터 추출 프로세스의 세부 사항을 확정하기 위한 최종 컬럼 정의서를 작성합니다. 이 정의서는 Secretary 에이전트가 데이터 추출 및 정제 작업을 수행하는 데 필요한 명확한 구조를 제공합니다.

**목표:** 연구과제 데이터 추출 및 분석을 위한 최종 표준 컬럼 정의서 (Schema Definition)

| No. | 컬럼명 (Column Name) | 데이터 타입 (Data Type) | 필수 여부 (Required) | 설명 (Description) | 비고 (Notes/Source) |
| :---: | :--- | :--- | :---: | :--- | :--- |
| 1 | **연구과제ID** | String/Integer | 필수 | 각 연구과제의 고유 식별자 (기관/시스템별 고유 번호) | 기관별 관리 코드 포함 |
| 2 | **과제명 (국문)** | String | 필수 | 연구과제의 전체 명칭 (공식 명칭) | 원문 기준 |
| 3 | **과제명 (영문)** | String | 선택 | 연구과제의 영문 명칭 (필요시) | 번역 필요 시 플래그 지정 |
| 4 | **등록기관** | String | 필수 | 연구과제를 등록한 정부 부처 또는 공공 연구기관 명칭 | 예: 과학기술정보통신부, KIST 등 |
| 5 | **세부기관** | String | 필수 | 연구과제를 주관하는 세부 수행 기관 명칭 | 예: 한국전자통신연구원, 특정 연구소 등 |
| 6 | **과제분야** | String | 필수 | 연구과제의 핵심 기술 분야 분류 (예: AI, 바이오, 에너지 등) | 표준화된 분류 체계 사용 권장 |
| 7 | **연구목적** | Text | 필수 | 해당 연구과제를 통해 달성하고자 하는 최종 목표 및 목적 | 상세 설명 필요 |
| 8 | **연구내용 요약** | Text | 필수 | 연구과제의 핵심적인 수행 내용 및 방법론 요약 | 3줄 이내 압축 필요 |
| 9 | **연구기간** | Date Range | 필수 | 연구과제의 시작일 및 종료일 (YYYY-MM-DD 형식) | 기간의 유효성 검사 필요 |
| 10 | **예산규모 (원)** | Integer | 필수 | 연구과제에 할당된 총 예산 규모 | 단위: 원 (또는 통화 단위 명시) |
| 11 | **지원상태** | String | 필수 | 현재 연구과제의 상태 (예: 공고, 선정, 진행 중, 종료) | 상태 변화 추적용 |
| 12 | **공고일자** | Date | 필수 | 해당 연구과제가 공식적으로 공고된 날짜 | 데이터 수집의 시점 파악 |
| 13 | **출처링크** | URL | 필수 | 해당 연구과제 정보의 공식 등록/공고 페이지 링크 | **출처 링크 필수** (추적 가능해야 함) |
| 14 | **ALTIT 매칭 점수 (AMS)** | Float | 선택 | ALTIT KOREA의 제안서 적합도 평가 점수 (0.0 ~ 1.0) | **Researcher/Developer 협의 필요** |
| 15 | **특이사항** | Text | 선택 | 데이터 수집 시 발견된 특이점, 비정형 데이터, 추가 분석 필요 사항 | 자유 서술 |
