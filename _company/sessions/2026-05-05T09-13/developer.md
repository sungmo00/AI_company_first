### 1. 핵심 모듈 구현 (Phase 2) 기술적 난이도 분석

단계 2는 Researcher가 승인한 데이터 추출 모듈 초안(API/Crawler Hook)을 실제 운영 가능한 수준으로 구현하고, 데이터 무결성을 확보하는 핵심 단계입니다.

#### A. 모듈별 기술 복잡도 평가 (Complexity Score)

| 모듈 ID | 모듈 명칭 | 주요 기능 범위 | 예상 기술 난이도 (1-5, 5가 최상) | 주요 위험 요소 |
| :--- | :--- | :--- | :--- | :--- |
| **M2.1** | 타겟 기관별 API 연동 및 데이터 파싱 | 확정된 접근 경로 기반의 동적/정적 API 호출, 응답 구조화(JSON/XML 파싱) | 4.5 | 기관별 API의 비표준화, Rate Limiting 정책의 엄격함 |
| **M2.2** | 데이터 정규화 및 품질 검증 (Validation) | 수집된 원시 데이터를 회사 표준 스키마(Pydantic 모델)로 변환하고, 누락/오류 데이터 필터링 | 4.0 | 비즈니스 로직(AMS 가중치 적용)의 복잡성 및 예외 처리 범위 |
| **M2.3** | 데이터 파이프라인 통합 및 안정화 (Orchestration) | 추출, 정제, 저장(DB/Data Lake) 간의 비동기적 데이터 흐름 관리 및 에러 복구 로직 구현 | 5.0 | 분산 시스템 환경에서의 데이터 일관성 유지 및 장애 복구 메커니즘 설계 |

### 2. 기술 스택 업그레이드 예산 산출 (Contingency Budget)

현재 설계된 초기 스택(Proof-of-Concept 수준)에서 실제 운영 환경에 필요한 안정성, 확장성, 보안을 확보하기 위한 스택 업그레이드 비용을 산출합니다.

#### A. 필요 기술 스택 업그레이드 항목

| 구분 | 현재 예상 스택 (PoC) | 목표 운영 스택 (Production Ready) | 업그레이드 필요성 |
| :--- | :--- | :--- | :--- |
| **데이터 추출** | 기본 `requests`/`BeautifulSoup` 기반 크롤링 | 고성능 비동기 처리 프레임워크 (e.g., `Aiohttp`, Scrapy with advanced throttling) | 동시성 처리 능력 및 대규모 데이터 수집 속도 확보 |
| **데이터 파이프라인** | 단순 스크립트 기반의 순차적 실행 | 메시지 큐 기반 비동기 처리 (e.g., Kafka/RabbitMQ), Workflow Orchestration (Airflow) | 시스템의 내결함성(Fault Tolerance) 및 모니터링 강화 |
| **인프라/보안** | 로컬 환경 또는 단순 VM 기반 | 클라우드 기반(AWS/GCP), IAM 기반 접근 제어, Secrets Management (Vault) | 보안 강화 및 확장성/탄력성 확보 |

#### B. 예산 산출 (Contingency Budget)

예산은 **'인력 투입 비용(Manpower)'**과 **'도구/라이선스 비용(Tooling)'**으로 분리하여 산출합니다. (기간: 3개월 집중 개발 및 통합)

| 예산 항목 | 상세 내용 | 산출 근거 (Man-Month 기준) | 예상 비용 범위 (USD) | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **인력 투입 (Up-skilling/Implementation)** | 백엔드 개발자 1명 (고성능 비동기 구현), DevOps 지원 0.5 FTE | 3 Man-Month (고난도 모듈 구현) | $15,000 - $25,000 | 숙련된 엔지니어의 집중 투입 비용. (최소 3개월) |
| **도구/인프라 (Tooling & Infrastructure)** | 메시지 큐 설정, CI/CD 파이프라인 구축 비용, 클라우드 초기 세팅 | $3,000 - $5,000 (초기 설정 및 테스트 환경) | $3,000 - $5,000 | 안정적인 운영을 위한 인프라 구축 비용. |
| **총 기술 스택 업그레이드 예산 (Contingency)** | **개발 및 인프라 안정화** | - | **$18,000 - $30,000+** | **이 범위 내에서 안정적인 운영 환경을 구축 가능.** |

**결론:** 단계 2의 복잡도(4.5~5.0)를 고려할 때, **최소 $18,000**의 예산은 필수적이며, 안정적인 운영을 위해서는 **$30,000** 수준의 예산을 확보하여 고성능 비동기 처리 및 분산 시스템 통합에 필요한 엔지니어링 리소스를 확보해야 합니다.
