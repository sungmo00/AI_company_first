Phase 1 (데이터 인프라 확립)의 구체적인 Task Breakdown과 각 마일스톤별 예상 소요 시간(Effort Estimation)을 Researcher와 Developer에게 요청하여 상세화하는 로드맵 초안을 작성하겠습니다. 이는 최종 실행 계획(Action Plan) 수립의 핵심 기반이 될 것입니다.

### Phase 1: 데이터 인프라 확립 로드맵 (초안)

**최종 목표:** 정부 및 공공기관 연구과제 조사 및 제안서 제출 프로세스 전반의 실행 로드맵(Action Plan) 확정.

| 단계 (Phase) | 핵심 목표 (Goal) | 주요 산출물 (Deliverables) | 담당 에이전트 | 예상 소요 시간 (Effort Estimation) | 의존성 (Dependencies) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **P1-1: 범위 및 데이터 요구사항 확정** | 조사 대상 기관/분야의 최종 범위와 필요한 데이터 항목(Schema)을 확정한다. | 1. 최종 타겟 기관 리스트 (Top N) 및 우선순위 매트릭스. 2. 최종 데이터 스키마 (Schema Definition VFinal). 3. 기관별/분야별 검색 가이드라인 초안. | Researcher (주도), Developer (검토) | 3일 | DB 스키마 V1/매핑 로직 설계 완료 (완료), 초기 타겟 기관 목록 확정 (완료) |
| **P1-2: 데이터 추출 인프라 설계** | 확정된 스키마를 기반으로 실제 데이터를 수집할 수 있는 기술적 인프라(API/크롤링 전략)를 설계한다. | 1. 기관별 데이터 추출 시나리오 (Step-by-Step). 2. 핵심 데이터 추출 모듈 API 인터페이스 초안 (DB-SOP 매핑). 3. AMS 가중치 적용 로직의 데이터 기반 타당성 검토 결과. | Developer (주도), Researcher (검토) | 4일 | 최종 데이터 스키마 확정 (P1-1 완료), DB-SOP 연동 로직 상세 설계 (완료) |
| **P1-3: 기술 검증 및 통합** | 설계된 인프라의 기술적 실현 가능성과 병목 현상을 분석하고, 모든 컴포넌트 간의 연동을 검증한다. | 1. 기술적 구현 가능성/병목 현상 분석 보고서. 2. 최종 Action Plan의 기술적 검토 체크리스트 (QA). 3. 개발팀용 시각적 구현 브리프 초안 (Designer 협업). | Developer, Designer (협력) | 3일 | P1-2 완료, API 인터페이스 초안 확정 (완료) |
| **P1-4: 최종 로드맵 확정** | 모든 기술적 검토 결과를 통합하여 실행 가능한 최종 로드맵(Action Plan)을 완성한다. | 1. **최종 실행 계획 (Final Action Plan)**: 상세 Task, 담당자, 기한 명시. 2. 리소스 배분 및 예산 상세 내역 (CEO 보고용). | Researcher (최종 정리), 전 에이전트 (검토) | 2일 | P1-3 완료, 모든 기술 검증 완료 |

### 에이전트별 역할 분배 및 요청 사항 (Action Plan)

**1. Researcher에게 요청할 내용:**
*   **Task Focus:** P1-1 단계에서 정의된 '최종 데이터 스키마(Schema Definition VFinal)'와 '기관별/분야별 검색 가이드라인 초안'을 기반으로, 각 단계별로 **데이터 수집의 현실성 및 데이터 요구사항의 구체화**에 집중하여 상세 정의를 완료해 주세요.
*   **Output Expectation:** P1-1 산출물(기관별 가이드라인, 최종 스키마 정의)의 초안을 완성하고, P1-2 단계에서 Developer가 바로 착수할 수 있도록 명확한 데이터 갭(Gap)을 최소화해 주세요.

**2. Developer에게 요청할 내용:**
*   **Task Focus:** P1-2 단계에서 Researcher가 제공한 데이터 요구사항을 기반으로, **실제 API/크롤링 시나리오**를 설계하고, P1-3 단계에서 요구될 **기술적 검증 항목 리스트(Checklist)**를 구체화해 주세요.
*   **Output Expectation:** P1-2 산출물(추출 시나리오, API 인터페이스 초안)의 기술적 완성도를 높이고, P1-3 단계에서 필요한 모든 검증 포인트를 포함한 체크리스트를 제공해 주세요.

**3. Designer에게 요청할 내용 (P1-3 지원):**
*   **Task Focus:** P1-3 단계에서 최종 Action Plan의 시각화 및 개발팀과의 소통을 위해, **'기술적 구현 가능성 분석 보고서'**를 기반으로 개발팀이 이해하기 쉬운 **시각적 구현 브리프(UX/UI 초안)**를 준비해 주세요.
*   **Output Expectation:** 기술적 제약사항과 성공 경로를 시각적으로 명확히 전달할 수 있는 초기 디자인 가이드라인을 준비해 주세요.
