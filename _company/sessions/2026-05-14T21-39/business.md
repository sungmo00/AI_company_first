## 최종 실행 로드맵 (Action Plan) 확정

Researcher가 정의한 Phase 2.1 세부 Task Breakdown을 기반으로, 프로젝트의 성공적인 완료를 위해 리소스 배분(인력/시간) 및 각 Task별 최종 완료 기한을 포함한 실행 로드맵(Action Plan)을 확정합니다.

**전략:**
리소스는 **P2.1-T2 (데이터 수집 인프라 구축)**에 가장 높은 비중을 할당하여, 데이터 확보의 기술적 장애물을 선제적으로 제거하는 데 집중합니다. P2.1-T1 (환경 분석)은 T2의 방향성을 설정하는 데 사용되며, T3(Pilot 데이터 수집)는 T2가 안정화된 후 병렬적으로 시작합니다.

### 2. Task별 구체적 실행 계획 및 지시사항

**P2.1-T1: 타겟 기관/분야 매핑 프레임워크 완성**
*   **목표:** ALTIT KOREA의 강점(기술/데이터)과 공공기관 요구사항을 연결하는 'Relevance 점수 모델링 기준'의 기반을 마련합니다.
*   **실행 지시:** Researcher는 T1 프레임워크 초안을 작성하고, Business는 해당 프레임워크의 비즈니스적 유효성을 검토하여 'Relevance 점수 모델링 기준'의 초기 가중치(Weighting Factor)를 정의해야 합니다.

**P2.1-T2: 데이터 추출 모듈(API/크롤링) 초기 설계 및 검증 (Critical Path)**
*   **목표:** 연구과제 데이터 확보의 기술적 병목을 해결합니다.
*   **실행 지시:** Developer는 P2.1-T1에서 정의된 타겟 기관별 데이터 요구사항(Need)을 기반으로, API Endpoint 명세 초안과 크롤링 전략을 구체화해야 합니다. Researcher는 이 설계가 실제 데이터 수집에 현실적인지 검증하는 피드백을 즉시 제공해야 합니다.

**P2.1-T3: 핵심 연구과제 DB 초기 샘플링 및 검증 (Pilot)**
*   **목표:** P2.1-T2에서 구축된 인프라를 사용하여 실제 데이터를 수집하고, 데이터 정제 가능성을 확인합니다.
*   **실행 지시:** Researcher는 T2에서 정의된 Schema에 맞춰 최소 5개 기관의 데이터를 수집하고, 데이터 품질(정합성) 검증 보고서를 작성해야 합니다.

**P2.1-T4: 가중치 및 매칭 로직 개발 (MVP)**
*   **목표:** 수집된 데이터와 기관 요구사항을 매칭하여 '최적의 연구과제'를 선별하는 핵심 알고리즘을 구현합니다.
*   **실행 지시:** Researcher는 T3에서 확보된 샘플 데이터를 활용하여, P2.1-T1에서 정의한 Relevance 점수 모델을 적용하는 MVP(Minimum Viable Product) 로직을 개발해야 합니다.

**P2.1-T5: 제안서 템플릿 및 초기 콘텐츠 개발**
*   **목표:** 검증된 로직(T4)을 기반으로, 실질적인 제안서 제출 단계로 넘어갈 수 있는 뼈대(템플릿)를 마련합니다.
*   **실행 지시:** Researcher는 T4의 결과물(매칭 로직)을 바탕으로, 연구과제 제안서의 핵심 구조와 필수 포함 요소를 담은 초안을 작성하고, Business는 이 템플릿의 '친근한 톤앤매너'가 브랜드 정체성에 부합하는지 최종 검토해야 합니다.
