ALTIT 매칭 점수 (AMS) 계산 로직 상세\n\n**목표:** 입력된 연구과제 데이터($D$)를 기반으로 ALTIT 적합도 점수($AMS$)를 산출합니다.\n\n**공식:** $$AMS = \sum_{i=1}^{N} (w_i \times S_i)$$ \n\n*   $w_i$: $i$번째 평가 항목의 가중치 (Researcher 정의). \n*   $S_i$: $i$번째 항목에 대한 정규화된 점수 ($0 \le S_i \le 1$).\n\n**핵심 가중치 정의 (Researcher Input):**\n*   $w_{\text{AreaMatch}}$: 0.4 (연구 분야 일치도)\n*   $w_{\text{Novelty}}$: 0.3 (연구의 참신성/혁신성)\n*   $w_{\text{GovtFit}}$: 0.2 (정부 과제 적합성)\n*   $w_{\text{Keywords}}$: 0.1 (핵심 키워드 일치도)\n\n**정규화 점수 ($S_i$) 계산 방법 예시 (Title Similarity $S_{\text{Title}}$):**\n$$S_{\text{Title}} = \text{CosineSimilarity}(\text{Embedding}(D.\text{title}), \text{Embedding}(\text{Target\_Criteria}))$$ \n\n*   **구현 고려사항:** 임베딩 모델(예: BERT)의 선택 및 데이터셋 구축이 필요함. 현재는 초기 단계로, 개발 단계에서 모델 선정 후 정교화 예정.\n\n## 3. 데이터 추출/매핑 흐름 (Extraction/Mapping Flow)\n1.  **Data Extraction:** Phase 1 결과 $\rightarrow$ Raw Data Set.\n2.  **Data Cleaning:** Phase 2 실행 $\rightarrow$ Standardized Data Set.\n3.  **Feature Engineering & Scoring:** Phase 3 실행 $\rightarrow$ AMS Score 계산.\n4.  **Final Load:** Final Structured Data Set $\rightarrow$ `research_projects` Table.\n\n--- \n*본 문서는 DB 스키마 설계와 AMS 계산 로직의 초기 프레임워크이며, Developer의 최종 구현 검토를 위해 준비되었습니다.*" > sessions/2026-06-04T04-15/developer.md
